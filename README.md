# Speed Controller Turbo

ส่วนขยาย Chrome สำหรับปรับความเร็ววิดีโอและเปิด `Turbo Mode` ได้ทั้งจาก floating panel และ popup

## ฟีเจอร์

- ปรับความเร็ววิดีโอได้ตั้งแต่ `x1` ถึง `x16`
- มี floating panel บนหน้าเว็บเพื่อควบคุมแบบเร็ว
- มี popup สำหรับเปิด/ปิด `Turbo Mode`
- `Turbo Mode` บังคับวิดีโอให้เล่นที่ `x16`
- จำค่าความเร็วและสถานะ Turbo ไว้ใน `chrome.storage.local`
- ค้นหา `<video>` บนหน้าปัจจุบัน และแสดงรายการให้เลือกปิดเป็นรายคลิปได้
- เอาเมาส์ชี้รายการแล้วมีกรอบไฮไลท์ตำแหน่งวิดีโอในหน้า

## ติดตั้งแบบใช้งานเอง

1. เปิด `chrome://extensions`
2. เปิดโหมด `Developer mode`
3. กด `Load unpacked`
4. เลือกโฟลเดอร์โปรเจกต์นี้
5. เปิดหน้าเว็บที่มีวิดีโอ แล้วลองใช้ปุ่ม `Turbo Mode`

## วิธีใช้งาน

### Floating Panel

- กดปุ่มสปีดเพื่อเปลี่ยนความเร็ว
- กด `Turbo Mode` เพื่อบังคับวิดีโอทั้งหมดที่อนุญาตให้เป็น `x16`
- ลากแถบหัว panel เพื่อย้ายตำแหน่ง
- กดปุ่มย่อ/ขยายเพื่อซ่อนรายการบางส่วน

### Popup

- เปิด popup ของ extension
- ใช้สวิตช์ `Turbo Mode` เพื่อเปิด/ปิดโหมดนี้
- สถานะจะถูกซิงก์กับหน้าเว็บทันที

### Turbo Targets

- ส่วน `Turbo Targets` จะสแกนวิดีโอทั้งหมดบนหน้าปัจจุบัน
- ติ๊กออกเพื่อยกเว้นคลิปนั้นจาก Turbo Mode
- เอาเมาส์ชี้รายการเพื่อดูกรอบไฮไลท์บนวิดีโอจริง

## Keyboard Shortcuts

- `]` เพิ่มสปีด
- `[` ลดสปีด
- `\` รีเซ็ตเป็น `x1`

## โครงสร้างไฟล์

- `content.js` คุม logic ของ panel, Turbo Mode และการสแกนวิดีโอ
- `popup.html` คุม popup ของ extension
- `styles.css` คุมหน้าตา panel และรายการ Turbo Targets
- `manifest.json` คุมสิทธิ์และการ inject script

## การทำงานของ Turbo Mode

- เมื่อเปิด Turbo Mode ระบบจะพยายามตั้งวิดีโอที่อนุญาตไว้เป็น `x16`
- ถ้าปิด Turbo Mode ระบบจะกลับไปใช้สปีดปกติที่ผู้ใช้เลือก
- รายการที่ถูกติ๊กออกจะไม่ถูกบังคับเป็น `x16`
- สถานะทั้งหมดเก็บใน `chrome.storage.local` เพื่อให้จำข้ามหน้าได้

## Troubleshooting

### ไม่เห็น panel หรือ Turbo Mode ไม่ทำงาน

- ตรวจว่าได้ `Reload` extension หลังแก้ไฟล์แล้วหรือยัง
- ตรวจว่าเปิดหน้าเว็บที่มี `<video>` จริงหรือไม่
- ถ้าคลิปอยู่ใน `iframe` คนละโดเมน อาจต้องเพิ่มการรองรับเพิ่มเติม

### เปิดบนเว็บอื่นแล้วไม่ทำงาน

- ตรวจ `manifest.json` ว่ามี `matches: ["<all_urls>"]` แล้ว
- โหลด extension ใหม่ทุกครั้งหลังแก้ `manifest.json`

## หมายเหตุ

โปรเจกต์นี้ออกแบบมาให้ทดลองและปรับแต่งต่อได้ง่าย ถ้าต้องการต่อยอดเพิ่ม เช่น

- ปุ่ม `Exclude all` / `Include all`
- แสดง thumbnail ของคลิปใน Turbo Targets
- รองรับการตรวจจับวิดีโอใน `iframe` มากขึ้น

สามารถต่อจากโครงนี้ได้เลย
