# Speed Controller Turbo (v3.2 Minimal)

ส่วนขยาย (Extension) สำหรับ **Google Chrome / Microsoft Edge / Brave** ช่วยปรับความเร็ววิดีโอได้ทุกเว็บตั้งแต่ `x0.25` ถึง `x16`, เร่งและปิดเสียงโฆษณาอัตโนมัติ, แยกสปีดอิสระแต่ละเว็บ และคลิก **"ต้องการเรียนบทถัดไป"** อัตโนมัติสำหรับคอร์ส E-Learning

---

## 1. วิธีติดตั้ง (สำหรับมือใหม่ ไม่เคยใช้ Extension ก็ทำตามได้)

> ใช้เวลาไม่ถึง 1 นาที และไม่ต้องลงโปรแกรมเสริมใดๆ

### ขั้นตอนที่ 1: ดาวน์โหลดไฟล์
1. กดปุ่มสีเขียว **`<> Code`** ด้านบนขวาของหน้า GitHub นี้ แล้วเลือก **`Download ZIP`**
2. เมื่อโหลดเสร็จ ให้คลิกขวาที่ไฟล์ `.zip` แล้วกด **Extract All... / แตกไฟล์** เก็บไว้ในโฟลเดอร์ที่หาเจอง่าย (เช่น `Documents\youtube-speed-extension`)
   - **ข้อควรระวัง:** ห้ามลบหรือย้ายโฟลเดอร์นี้หลังจากติดตั้งเสร็จ เพราะเบราว์เซอร์จะเรียกใช้ไฟล์จากโฟลเดอร์นี้ตลอด

### ขั้นตอนที่ 2: ติดตั้งลงเบราว์เซอร์
1. เปิด Chrome (หรือ Edge / Brave) พิมพ์คำนี้ในช่อง URL ด้านบนแล้วกด Enter:
   ```text
   chrome://extensions/
   ```
   *(ถ้าใช้ Edge ให้พิมพ์ `edge://extensions/`)*
2. เปิดสวิตช์ **โหมดนักพัฒนาซอฟต์แวร์ (Developer mode)** ที่มุมขวาบนให้เป็นสีน้ำเงิน
3. กดปุ่ม **โหลดส่วนขยายที่คลายบีบอัดแล้ว (Load unpacked)** ที่มุมซ้ายบน
4. เลือกโฟลเดอร์ที่แตกไฟล์ไว้ *(ต้องเป็นโฟลเดอร์ที่ข้างในมีไฟล์ `manifest.json` อยู่)* แล้วกด **Select Folder**

### ขั้นตอนที่ 3: ปักหมุดไอคอนให้เห็นง่ายๆ
1. กดไอคอนรูป **จิ๊กซอว์ (🧩)** ที่มุมขวาบนของเบราว์เซอร์
2. หาชื่อ **Speed Controller Turbo** แล้วกดรูป **หมุด (📌)** ให้เป็นสีน้ำเงิน
3. ไอคอน `>>` สีดำมินิมอลจะมาอยู่บนแถบด้านบนพร้อมใช้งาน — **รีเฟรชหน้าเว็บวิดีโอที่เปิดค้างไว้ 1 ครั้ง** แล้วเริ่มใช้ได้เลย

## 2. วิธีใช้งานเบื้องต้น

คลิกที่ไอคอน `>>` มุมขวาบนของเบราว์เซอร์ จะมีหน้าต่างควบคุมเด้งขึ้นมา:

| การควบคุม | วิธีใช้ |
| :--- | :--- |
| **ปรับสปีดไว** | กดปุ่ม `x1`, `x1.5`, `x2`, `x3`, `x4`, `x6`, `x8`, `x16` หรือลากแถบเลื่อน |
| **ปรับละเอียด / รีเซ็ต** | กดปุ่ม `−` / `+` (ทีละ `0.25x`) หรือกด `1x` เพื่อรีเซ็ตกลับปกติ |
| **ดูสปีดโดยไม่ต้องเปิดป๊อปอัป** | ตัวเลขสปีดจะขึ้นเป็นป้ายเล็กๆ บนไอคอนส่วนขยายเลย (เช่น `1.5`, `2x`, `AD`) |
| **ใช้เมาส์ปรับบนวิดีโอ** | กด **`Ctrl` ค้างไว้ + เลื่อนลูกกลิ้งเมาส์** บนตัววิดีโอ |

### คีย์ลัด (Keyboard Shortcuts)
กดได้เลยขณะดูวิดีโอ (ไม่ต้องกดในช่องพิมพ์ข้อความ):
- **`]`** : เพิ่มความเร็ว
- **`[`** : ลดความเร็ว
- **`\`** : รีเซ็ตความเร็วเป็น `x1`
- **`t`** : เปิด/ปิด Ad Turbo
- **กด `Space` ค้างไว้** : เร่งชั่วคราวเป็น `x2.5` (ปล่อยแล้วกลับสปีดเดิม)

## 3. คำอธิบายแต่ละโหมด (เปิด-ปิดได้ในป๊อปอัป)

> สามารถเอาเมาส์ชี้เครื่องหมาย **`?`** ข้างแต่ละโหมดในป๊อปอัปเพื่ออ่านคำอธิบายสั้นๆ ได้ตลอดเวลา

- **Ad Turbo (x16 + Mute)** *(เปิดเป็นค่าเริ่มต้น)*
  เร่งความเร็วโฆษณาวิดีโอเป็น `x16` พร้อมปิดเสียงและช่วยกดปุ่มข้าม (Skip) ให้อัตโนมัติ เมื่อโฆษณาจบจะคืนเสียงและสปีดเดิมให้เอง
- **Per-Site Speed** *(เปิดเป็นค่าเริ่มต้น)*
  จำสปีดแยกอิสระแต่ละเว็บ เช่น YouTube ดู `x2`, TrueID ดู `x1.5`, เว็บเรียนดู `x16` โดยไม่ปนกัน
- **Floating Panel** *(เปิดเป็นค่าเริ่มต้น)*
  แผงควบคุมแบบลอยบนหน้าเว็บ ลากย้ายมุมได้ ยุบเป็นแคปซูลเล็กๆ ได้ และแสดงผลได้แม้ตอนดูแบบเต็มจอ (Fullscreen) — หากไม่ชอบให้บังจอสามารถปิดได้
- **Ad Blocker (7-Layer)** *(ปิดเป็นค่าเริ่มต้น)*
  ช่วยซ่อนแบนเนอร์และป๊อปอัปโฆษณารกตาบนหน้าเว็บ *(หากเว็บไหนแสดงผลผิดปกติ ให้ปิดโหมดนี้)*
- **Auto Next Lesson** *(ปิดเป็นค่าเริ่มต้น)*
  สำหรับเว็บเรียนออนไลน์ (E-Learning) ที่ขึ้นกล่องแจ้งเตือนจบบทเรียน — เมื่อเปิดโหมดนี้ ระบบจะคลิกปุ่ม **`ต้องการเรียนบทถัดไป`** ให้อัตโนมัติ *(แนะนำให้เปิดเฉพาะตอนเรียนคอร์ส)*

## 4. คำถามที่พบบ่อย (FAQ)

- **ติดตั้งเสร็จแล้วกดปรับสปีดไม่ทำงาน?**
  ให้กด **รีเฟรชหน้าเว็บ (F5)** 1 ครั้งสำหรับแท็บที่เปิดค้างไว้ก่อนติดตั้งส่วนขยาย
- **ทำไมโหลดโฟลเดอร์แล้วขึ้น Error "Manifest file is missing or unreadable"?**
  เกิดจากการเลือกโฟลเดอร์ชั้นนอกที่ซ้อนกันอยู่ (ตอนแตกไฟล์ ZIP มักสร้างโฟลเดอร์ซ้อน 2 ชั้น) ให้กดเข้าไปเลือกโฟลเดอร์ชั้นในที่มองเห็นไฟล์ `manifest.json`
- **วิธีอัปเดตเมื่อมีเวอร์ชันใหม่**
  นำไฟล์ใหม่มาวางทับในโฟลเดอร์เดิม (หรือ `git pull`) แล้วไปที่ `chrome://extensions/` กดปุ่ม **รีโหลด (↻)** ที่การ์ดของ Speed Controller Turbo จากนั้นรีเฟรชหน้าเว็บวิดีโอ

## โครงสร้างไฟล์

- [`manifest.json`](manifest.json) — ข้อมูลส่วนขยาย สิทธิ์การเข้าถึง และไอคอน
- [`content.js`](content.js) — ระบบควบคุมความเร็ว, Shadow DOM UI, Ad Turbo, Ad Blocker และ Auto Next Lesson
- [`background.js`](background.js) — Service Worker สำหรับอัปเดตตัวเลขสปีดบนไอคอน Chrome
- [`popup.html`](popup.html) / [`popup.js`](popup.js) — หน้าต่างควบคุมเมื่อกดไอคอนส่วนขยาย
- [`inject.js`](inject.js) — ตัวช่วยกดข้ามโฆษณาแบบปลอดภัย (Nonce-protected)
- [`styles.css`](styles.css) — สไตล์พื้นฐานของ Host Container
